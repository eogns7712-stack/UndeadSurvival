■ 1. 핵심 디자인 패턴

① 싱글톤 패턴 (Singleton Pattern)
적용 클래스: GameManager, AudioManager
설명: 게임 전체에서 하나만 존재해야 하는 관리 객체를 static instance로 보관합니다.
GameManager는 게임 상태, 경험치, 상점 재화, 보스전, 일시정지, 결과창 흐름을 관리하고, AudioManager는 BGM과 SFX 재생을 담당합니다.

② 오브젝트 풀링 패턴 (Object Pooling Pattern)
적용 클래스: PoolManager
설명: Enemy, Bullet, BombBullet, BombFragment, 폭발 VFX, 화염지대, 랜덤박스, 보스탄막 등 자주 생성/소멸되는 오브젝트를 Instantiate/Destroy하지 않고 미리 만든 풀에서 꺼내 재사용합니다.
수류탄 파편, 폭발 이펙트, 화염지대, 보스 사망 폭발, 보상 코인도 풀링 흐름을 사용합니다.

③ 데이터 기반 설계 (ScriptableObject)
적용 클래스: ItemData
설명: 무기, 장비, 수류탄의 아이콘, 이름, 설명, 기본 수치, 레벨별 증가량, 발사체 프리팹, 손에 표시될 스프라이트, 초월 발사체/설명을 유니티 에셋 데이터로 관리합니다.
코드에서 모든 수치를 직접 고정하지 않고, 인스펙터와 ItemData를 통해 조절할 수 있게 구성되어 있습니다.

④ 상태 기반 게임 흐름
적용 클래스: GameManager, Spawner, Enemy, BossAttack, BossHPUI, PauseUI, Result
설명: 일반 웨이브, 보스전, 일시정지, 사망, 승리 상태를 GameManager의 isLive, isBossBattle, isBossCleared, isPaused 값으로 구분합니다.
각 시스템은 이 상태값을 확인해서 스폰, 공격, UI 표시, 시간 흐름을 제어합니다.

■ 2. 클래스별 상세 기능 및 구조 분석

□ 2.1 코어 매니저

GameManager : 전체 게임 상태 관리
└ 캐릭터 선택 후 게임 시작, 체력/레벨/경험치/킬 수 초기화, 게임 시간과 보스전 시간 제어, 승리/패배 처리, 결과창 출력, 일시정지, 보스전 연출, 상점 재화와 강화 저장값을 담당합니다.
└ 일반 시간이 끝나면 보스전 루틴을 시작합니다. 잡몹 정리, 시간정지, 경고 이미지 표시, 보스 생성, BossHP UI 활성화, 보스 줌인 연출, 보스전 타이머 전환을 순서대로 처리합니다.
└ 보스 처치 시 슬로우, 카메라 흔들림, 폭발 VFX, 보상 코인 생성, 상점 재화 지급, 승리 결과창 출력을 처리합니다.

PoolManager : 오브젝트 풀 관리
└ 인스펙터에 등록된 prefabs 배열을 기준으로 pools 배열을 만들고, 필요한 오브젝트를 Get(id)로 꺼내 씁니다.
└ 비활성화된 오브젝트가 있으면 재사용하고, 없으면 새로 생성하여 풀에 추가합니다.

AudioManager : 사운드 제어
└ BGM 플레이어와 여러 개의 SFX 플레이어를 관리합니다.
└ Sfx enum을 통해 Dead, Hit, LevelUp, Lose, Melee, Range, Select, Win 효과음을 재생합니다.

AchiveManager : 업적 및 캐릭터 해금 관리
└ PlayerPrefs에 저장된 업적 상태를 읽어 캐릭터 선택창의 잠금/해금 버튼을 갱신합니다.
└ 현재 스크립트 기준으로 감자농부는 처치 수 조건, 다른 해금 조건은 보스 클리어 플래그(isBossCleared)를 기준으로 검사합니다.

ShopManager : 상점 UI와 구매 처리
└ 상점 패널을 열고 닫으며, 각 상점 항목의 레벨/가격/최대레벨 표시를 갱신합니다.
└ 구매 버튼이 눌리면 GameManager.TryBuyShopUpgrade()에 구매 가능 여부, 재화 차감, 저장 처리를 맡깁니다.

□ 2.2 플레이어, 적, 스폰

Player.cs : 플레이어 이동, 피격, 경험치 버퍼 처리
└ New Input System의 OnMove 입력값을 받아 Rigidbody2D로 이동합니다.
└ 적과 충돌 중이면 체력을 감소시키고, 보스 몸박 데미지는 일반 몬스터보다 높은 배율로 처리합니다.
└ 경험치 보석과 금색 코인에서 들어온 경험치는 pendingExp에 임시 저장한 뒤 Update에서 GameManager.GetExp()로 전달합니다. 이 구조로 한 번에 많은 경험치를 얻어도 레벨업 초과 경험치가 사라지지 않게 처리합니다.
└ 체력이 0 이하가 되면 사망 애니메이션과 GameManager.GameOver() 흐름으로 이어집니다.

Enemy.cs : 일반 몬스터와 보스의 공통 적 처리
└ 일반 몬스터는 플레이어를 추적하고, 너무 멀어지면 플레이어 근처로 재배치됩니다.
└ 일반 몬스터는 피격 시 넉백과 Hit 애니메이션을 사용합니다.
└ 보스는 넉백/강제 재배치를 적용하지 않고, Hit 애니메이션 대신 색상 깜빡임으로 피격 표현을 처리해 이동이 끊기지 않게 합니다.
└ 일반 몬스터 사망 시 킬 수 증가, 상점 재화 증가, 경험치 보석 드롭, 랜덤박스 확률 드롭을 처리합니다.
└ 보스 사망 시 GameManager.BossDead()를 호출하여 보스 클리어 연출과 보상을 실행합니다.

Spawner.cs : 일반 몬스터와 보스 스폰
└ 일반 웨이브 중에는 gameTime을 기준으로 spawnData 레벨을 계산하고, 현재 레벨에 맞는 몬스터를 풀에서 꺼내 생성합니다.
└ 상점의 몬스터 리젠 주기 감소 효과는 spawnTime에 곱해져 적용됩니다.
└ 보스전이 시작되면 일반 몬스터 스폰을 중단합니다.
└ SpawnBossMonster()는 bossPoolId와 bossData를 사용해 보스를 한 번만 생성하고, GameManager가 BossHP UI와 줌인 연출에 사용할 Enemy 참조를 반환합니다.

Scanner.cs : 주변 적 탐색
└ 플레이어 주변 원형 범위에서 targetLayer의 적을 탐색합니다.
└ 가장 가까운 적을 nearestTarget으로 보관하여 원거리 무기와 수류탄 투척 방향 계산에 사용합니다.

Reposition.cs : 무한 맵 및 멀어진 오브젝트 재배치
└ 플레이어가 타일 영역을 벗어나면 타일을 플레이어 이동 방향으로 옮겨 무한 맵처럼 보이게 합니다.
└ 일반 몬스터가 너무 멀어졌을 때 재배치하는 흐름도 지원하지만, 보스는 이 대상에서 제외됩니다.

□ 2.3 무기, 수류탄, 발사체

Weapon.cs : 근접무기와 원거리무기 처리
└ id 0 계열 근접무기는 플레이어 주변에 무기를 배치하고 회전시키는 방식으로 공격합니다.
└ id 1 계열 원거리무기는 Scanner가 찾은 nearestTarget 방향으로 Bullet을 발사합니다.
└ 무기 레벨업과 초월 단계를 관리하며, 총은 1단계 초월 라이플, 2단계 초월 샷건 구조를 가집니다.
└ 공격속도는 캐릭터 보정, 장갑, 상점 공속 보너스를 반영하되 과도하게 낮아져 음수가 되지 않도록 보정됩니다.

Bullet.cs : 일반 탄환 처리
└ 발사 방향, 데미지, 관통 수, 최대 사거리를 받아 이동합니다.
└ 적에게 닿으면 데미지를 주고 관통 수를 감소시키며, 관통 수가 끝나거나 최대 사거리를 넘으면 비활성화되어 풀로 돌아갑니다.

Bomb.cs : 수류탄 무기와 수류탄 투사체 처리
└ 수류탄은 Weapon/Bullet에서 분리되어 Bomb.cs가 전담합니다.
└ 무기 모드에서는 Scanner의 nearestTarget을 기준으로 수류탄을 투척합니다.
└ 투사체 모드에서는 목표 방향으로 날아가고, 적 충돌 또는 최대 사거리 도달 시 폭발합니다.
└ 기본 폭발 데미지를 주고, 초월 단계에 따라 파편 생성 또는 화염지대 생성을 추가합니다.
└ 수류탄 공격속도는 수류탄 자체 레벨, 장갑, 상점 공격속도 보너스를 반영합니다.

BombFragment.cs : 수류탄 파편 처리
└ 파편 수류탄 초월 시 생성되는 소형 발사체입니다.
└ 지정 방향으로 날아가고, 적에게 데미지를 주며, 관통 수 또는 최대 사거리 조건을 만족하면 비활성화됩니다.

BombFireZone.cs : 소이 수류탄 화염지대 처리
└ 소이 수류탄 초월 시 폭발 지점에 생성되는 지속 피해 영역입니다.
└ 유지 시간 동안 범위 안의 적에게 주기적으로 데미지를 주고, 시간이 끝나면 풀로 돌아갑니다.

BombExplosionFX.cs : 수류탄 및 보스 사망 폭발 VFX
└ 폭발 반경에 맞춰 원형 VFX를 키우고 줄이는 연출을 실행합니다.
└ 재생이 끝나면 오브젝트를 비활성화하여 풀링 재사용이 가능하게 합니다.

BossBullet.cs : 보스 탄막
└ BossAttack에서 초기화한 방향과 속도로 이동합니다.
└ 플레이어와 충돌하면 데미지를 주고, 최대 사거리 또는 수명이 끝나면 비활성화됩니다.

□ 2.4 아이템, 레벨업, 장비

ItemData.cs : 아이템 데이터 에셋
└ ItemType은 Melee, Range, Glove, Shoe, Heal, Bomb으로 구분됩니다.
└ 기본 데미지, 기본 개수, 레벨별 데미지/개수/속도, 아이콘, 설명, 발사체, 손 스프라이트, 초월 발사체와 초월 설명을 저장합니다.

Item.cs : 레벨업 선택지와 강화 적용
└ LevelUp UI에 표시될 아이콘, 이름, 레벨, 설명을 갱신합니다.
└ 선택 시 타입에 따라 Weapon, Bomb, Gear, Heal 로직을 실행합니다.
└ 기본 5레벨 이후에는 초월 단계 이름과 설명을 표시하고, 초월 단계별 전용 강화 로직을 적용합니다.
└ 수류탄은 Bomb 타입으로 분리되어 Bomb 컴포넌트를 생성하거나 강화합니다.

LevelUp.cs : 레벨업 선택창
└ 경험치가 필요량에 도달하면 게임을 일시 정지하고 선택지를 표시합니다.
└ 선택 가능한 아이템을 랜덤으로 구성하며, 숫자키/키패드 입력으로도 선택할 수 있습니다.
└ 선택 후 GameManager.Resume()으로 게임을 다시 진행합니다.

Gear.cs : 패시브 장비
└ 장갑은 무기와 수류탄의 공격속도에 영향을 줍니다.
└ 신발은 플레이어 이동속도에 영향을 줍니다.
└ 초월 이후에도 장비 효과가 누적 적용됩니다.

Hand.cs : 손에 든 장비 표시
└ 플레이어의 좌우 방향에 따라 손 오브젝트의 위치, 회전, sortingOrder를 갱신합니다.
└ 근접무기, 원거리무기, 수류탄을 각각 손에 든 스프라이트로 표시합니다.
└ 수류탄 손 오브젝트는 별도로 관리되며, 근접무기와 같은 레이어 기준을 따릅니다.

□ 2.5 획득물, 랜덤박스, 상점 보너스

ItemPickup.cs : 드롭 아이템과 흡수 처리
└ 경험치 보석, 랜덤박스, 금색 코인, 회복팩, 자석 아이템을 처리합니다.
└ 자석 효과가 있거나 플레이어가 가까이 있으면 플레이어 쪽으로 빨려 들어갑니다.
└ 상점의 아이템 흡수 거리 증가 효과는 magnetDistance에 더해져 적용됩니다.
└ 경험치 보석과 금색 코인은 Player.pendingExp를 통해 경험치가 안전하게 누적됩니다.

BoxOpen.cs : 랜덤박스 보상 처리
└ 랜덤박스 충돌 또는 열림 상태를 처리하고 보상 아이템을 생성합니다.
└ 랜덤박스 등장 시 살짝 튕겨나오는 연출이 적용되어 있습니다.

ShopManager.cs + GameManager.ShopUpgradeType : 상점 강화
└ 상점 재화는 몬스터 처치와 보스 처치 보상으로 증가합니다.
└ 상점 항목은 레벨업 필요 경험치 감소, 이동속도, 공격력, 공격속도, 최대체력, 몬스터 리젠시간 감소, 랜덤박스 확률 증가, 아이템 흡수 거리 증가로 구성됩니다.
└ 강화 레벨과 재화는 PlayerPrefs에 저장되어 다음 판 시작 시 적용됩니다.

□ 2.6 UI, 결과창, 일시정지

HUD.cs : 게임 중 HUD
└ 경험치, 레벨, 처치 수, 시간, 체력을 표시합니다.
└ Exp에는 현재 경험치 / 필요 경험치 텍스트도 함께 표시합니다.
└ 보스전 중에는 Timer 색상이 빨간색으로 바뀌고, 일반 시간 대신 보스전 남은 시간을 표시합니다.
└ 게임 종료 후 시간이 음수로 내려가지 않도록 남은 시간을 보정합니다.

BossHPUI.cs : 보스 체력 UI
└ 보스전 시작 시 BossHP 오브젝트를 활성화하고 체력바가 왼쪽에서 오른쪽으로 서서히 차는 등장 연출을 실행합니다.
└ 보스 체력 변화에 맞춰 슬라이더 값을 갱신합니다.
└ 70%, 40% 구간 마커를 표시해 보스 패턴 단계 변화를 시각적으로 안내합니다.

PauseUI.cs : 일시정지 상태창
└ 일시정지 시 PausePanel을 활성화하고 현재 장비 강화 단계와 상점 보너스 목록을 표시합니다.
└ 장비 상태는 텍스트 대신 아이콘 슬롯과 레벨 텍스트로 구성됩니다.
└ 상점 보너스는 종류별 아이콘, 이름, 현재 적용 값을 따로 표시합니다.

Result.cs : 결과창
└ 승리/패배 이미지를 전환합니다.
└ 이번 판 처치 수를 결과창에 표시합니다.

Follow.cs : 월드 오브젝트 UI 추적
└ 월드 좌표의 대상 오브젝트를 화면 좌표로 변환하여 체력바나 UI가 대상을 따라가게 합니다.

□ 2.7 보스전 전용 시스템

BossAttack.cs : 보스 탄막 패턴
└ 보스가 살아 있고 보스전 상태일 때 랜덤 패턴을 선택해 공격합니다.
└ 패턴 1: 보스 주변 원형 16방향 탄막.
└ 패턴 2: 플레이어 현재 위치를 향해 3발씩 4회 반복 발사.
└ 패턴 3: 모든 스폰 포인트에서 플레이어 현재 위치를 향해 한 발씩 발사. 이 패턴의 탄막 속도는 고정값을 사용합니다.
└ 패턴 사이 쿨타임, 탄막 속도, 경고 시간 등은 인스펙터에서 조절할 수 있습니다.
└ 보스 HP가 70%, 40% 이하가 되면 패턴 단계가 올라가고 공격 간격 감소, 탄막 개수 증가 등의 강화가 적용됩니다.
└ 탄막 발사 전 붉은 선 형태의 예고 장판을 표시합니다.

BossBullet.cs : 보스 탄막 이동과 충돌
└ BossAttack에서 받은 방향, 속도, 데미지, 사거리 값을 사용합니다.
└ 플레이어에게 닿거나 사거리/수명이 끝나면 풀로 회수됩니다.

■ 3. 데이터 흐름 요약 (Data Flow)

① 게임 시작
캐릭터 선택 버튼 클릭
→ GameManager.GameStart(playerId)
→ 상점 보정값 적용
→ 체력, 경험치, 킬 수, 게임 시간 초기화
→ 선택 캐릭터 기본 무기 지급(LevelUp.Select)
→ 상점 버튼 숨김, 일시정지 버튼 표시
→ 게임 진행 시작

② 일반 웨이브 진행
GameManager.Update에서 gameTime 증가
→ Spawner가 gameTime 기준 spawnData 레벨 계산
→ PoolManager에서 일반 Enemy를 꺼내 스폰
→ Enemy가 Player를 추적
→ Scanner가 가장 가까운 적을 탐색
→ Weapon/Bomb이 근접 회전, 총알 발사, 수류탄 투척을 실행
→ Bullet/Bomb/BombFragment/BombFireZone이 적에게 데미지 전달

③ 적 처치와 성장
Enemy 체력 0 이하
→ 일반 몬스터는 킬 수 증가, 상점 재화 증가, 경험치 보석 드롭, 랜덤박스 확률 드롭
→ ItemPickup이 경험치/코인을 Player.pendingExp에 적립
→ Player.Update가 pendingExp를 GameManager.GetExp()로 전달
→ 경험치가 필요량 이상이면 초과 경험치를 보존하면서 레벨업 반복 처리
→ LevelUp UI 활성화
→ Item 선택
→ Weapon/Bomb/Gear 강화 또는 회복
→ 게임 재개

④ 상점 강화 흐름
캐릭터 선택 화면에서 Shop 버튼 클릭
→ ShopManager.OpenShop()
→ 현재 재화와 각 강화 레벨/가격 표시
→ 구매 시 GameManager.TryBuyShopUpgrade()
→ 재화 차감, 강화 레벨 증가, PlayerPrefs 저장
→ 다음 게임 시작 또는 현재 적용 가능한 항목에 보정값 반영

⑤ 보스전 시작
일반 게임 시간이 maxGameTime에 도달
→ GameManager.StartBossBattle()
→ EnemyCleaner로 잡몹 정리
→ 시간 정지 및 Health UI 임시 숨김
→ WARNING 이미지와 붉은 오버레이 연출
→ Spawner.SpawnBossMonster()
→ BossHPUI.Show(boss)
→ BossHP 바 채우기 연출과 카메라 보스 줌인
→ bossTime으로 타이머 전환
→ 보스전 시작

⑥ 보스전 전투
BossAttack이 랜덤 패턴 선택
→ 경고선 표시
→ BossBullet을 풀에서 꺼내 발사
→ 보스 HP가 70%, 40% 이하로 내려가면 패턴 단계 강화
→ BossHPUI가 체력바를 계속 갱신
→ Player가 보스 또는 탄막에 맞으면 체력 감소

⑦ 보스 처치와 승리
Boss Enemy 체력 0 이하
→ Enemy.Die에서 GameManager.BossDead(bossPosition) 호출
→ isBossCleared true
→ 보스 HP UI 숨김
→ 슬로우, 카메라 흔들림, 폭발 VFX, 보상 코인 생성
→ 상점 재화 보상 지급
→ GameManager.GameVictory()
→ Result UI에서 승리 이미지와 이번 판 처치 수 표시
→ AchiveManager가 보스 클리어 조건 해금 검사 가능

⑧ 패배와 결과창
Player 체력 0 이하
→ GameManager.GameOver()
→ 게임 진행 상태 정리
→ Result UI에서 패배 이미지와 이번 판 처치 수 표시
→ BGM 정지, 패배 효과음 재생

⑨ 일시정지 흐름
게임 중 Pause 버튼 클릭
→ GameManager.TogglePause()
→ Time.timeScale = 0
→ PauseUI.Show()
→ 현재 장비 강화 단계와 상점 보너스 표시
→ Resume 버튼 클릭 시 PauseUI.Hide() 후 Time.timeScale 복구

■ 4. 현재 주요 밸런스 및 확장 포인트

① 상점 항목
레벨업 필요 경험치: 레벨당 3% 감소
이동속도: 레벨당 3% 증가
공격력: 레벨당 3% 증가
공격속도: 레벨당 3% 증가
최대체력: 레벨당 10% 증가
몬스터 리젠시간: 레벨당 3% 감소
랜덤박스 확률: 레벨당 1%p 증가
아이템 흡수 거리: 레벨당 고정 거리 증가

② 무기 초월
근접무기: 기본 단계 이후 초월 무기로 변경되며, 초월 이후 레벨업은 주로 데미지 증가 중심으로 처리됩니다.
원거리무기: 1단계 라이플, 2단계 샷건 구조를 가집니다.
수류탄: 1단계 파편 수류탄, 2단계 소이 수류탄 구조를 가집니다.

③ 보스전
일반 웨이브 종료 후 보스전으로 전환됩니다.
보스는 일반 몬스터와 다르게 넉백, 멀리 떨어졌을 때 강제 재배치, Hit 애니메이션 정지를 사용하지 않습니다.
보스는 패턴 예고, 페이즈 변화, 체력 UI 마커, 사망 연출, 보상 코인을 가집니다.

④ UI
캐릭터 선택 화면: 상점 버튼 표시
게임 진행 중: HUD, 일시정지 버튼 표시
보스전: BossHP, 빨간 타이머, WARNING 이미지 연출 표시
일시정지: 장비 상태와 상점 보너스 표시
결과창: 승리/패배와 이번 판 처치 수 표시
